# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People coordinating multiple Sparky agent chats and threads at the same time.

## Product Purpose

Sparky helps users delegate software work to AI agents while keeping them in control. The Activity Monitor makes active work, approval requests, and the next useful action visible in one place.

## Operating Context

Users may have several threads running across projects and environments. Some threads are working, some are waiting for input, and some need explicit user approval before continuing.

## Capabilities and Constraints

- Activity Monitor is an operational overview, not a log viewer or debugging console.
- User approval remains explicit for consequential agent actions.
- Threads must be easy to locate in the main sidebar and open from the monitor.
- Activity Monitor uses live thread shell state and routes actions back to the canonical thread UI.

## Brand Commitments

Preserve Sparky’s existing name, blue accent, application tokens, component language, typography, light/dark themes, and desktop-app behavior.

## Product Principles

- Make required attention unmistakable.
- Keep the user in control of agent actions.
- Reduce the effort needed to decide what to do next.
- Prefer concise operational state over technical detail.
