# Sparky v1.1.10 — Scheduled Tasks

Your automations, on your terms.

## What's New

**Scheduled Tasks** — Create, manage, and run automated tasks on a schedule. Set a prompt, pick a model, choose your frequency (hourly, daily, weekly), and Sparky handles the rest.

- **Full model control** — Pick any provider and model for each scheduled task. Your choice is saved and persists across sessions.
- **Task templates** — Spawn scheduled tasks directly from any conversation thread, carrying over the thread's model and runtime settings.
- **One-click run** — Trigger any scheduled task immediately from the dashboard, no waiting for the next interval.
- **Per-task history** — See every execution with status, duration, and output in a dedicated detail panel.
- **Rename & edit** — Update title, prompt, schedule, or model for any task without recreating it.

## Also in This Release

- **New OpenAI branding** — Updated to the 2025 OpenAI logo across the model picker and provider icons.
- **Model picker fixes** — Icons and model names now sit flush in the schedule dialog trigger; no more visual gaps.
- **Schedule bugfix** — Model selection now saves correctly when creating new tasks. Previously, newly created tasks would revert to the default model.

## Updating

Existing users will be prompted to update automatically. You can also download the latest installer from the [Releases page](https://github.com/darkness22s/sparky-1.1-source/releases/tag/v1.1.10).

**Platforms:** macOS (Apple Silicon + Intel), Windows x64, Linux (AppImage)
