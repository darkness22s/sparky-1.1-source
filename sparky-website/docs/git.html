Git Operations

Stage changes, commit, push, pull, switch branches. Works with GitHub, GitLab, or your own Git server.

How it works

Sparky interacts with git through the terminal. It can read the status, stage files, create commits, push, pull, and switch branches.

Common operations

Example prompts
"What files have changed?"
"Stage everything and commit with message fix login bug"
"Push to origin main"
"Create a branch called feature/dashboard"

Code review

Ask Sparky to review changes before you push:

Example prompts
"Review the changes in my current branch"
"Look for security issues in staged files"
