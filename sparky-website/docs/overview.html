GETTING STARTED

Overview

Sparky is a desktop AI coding assistant that reads your code, makes changes, runs commands, and searches your project — using the AI model you already have.

What's new in 1.1.3

  • Project-free chats keep general conversations separate from project files and workspace tools.
  • Clearer chat titles make project-free conversations easier to find later.
  • Provider-native metadata keeps the selected model and session details accurate.
  • More reliable sessions preserve provider context across follow-ups and restarts.
  • ImageView fallback lets supported models inspect workspace images or browser previews when the active model lacks vision.

Sparky checks for updates in the background. When a new version is ready, the app will show a notification so you can choose when to install it.

What is Sparky?

Sparky is a desktop application that acts as an AI pair programmer. It reads your codebase, understands the structure, and can make changes, run commands, search code — all through natural language.

Unlike cloud-based tools, Sparky runs on your machine. Your code is only sent to the AI provider you choose.

How it works

  1. Point Sparky at a project — it reads the structure
  2. Tell it what you need — in plain English
  3. Review the result — keep or revert

The Sidebar Panel

Open supporting tools beside the active thread. Each surface keeps the current project and task in view:

BrowserOpen a local app or URL and inspect the result.
TerminalRun tests, builds, package commands, and one-off scripts.
FilesBrowse the project tree and read the exact files involved.
DiffReview working-tree or thread changes before you commit.

Project-free chats

Use a project-free chat when you want an answer without sending a project workspace as context. Sparky keeps the conversation and provider session durable, but does not read files, memory, extensions, or MCP tools from a project until you open one.
