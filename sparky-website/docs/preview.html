Preview Websites

Open your HTML and CSS projects in a browser from inside Sparky.

How it works

Sparky can start a local development server and open your project in a browser.

Usage

Example prompts
"Open index.html in a browser"
"Start a dev server for this React app"
"Preview the landing page"

What works

  • Static HTML/CSS — any .html file
  • React, Vue, Svelte — runs the dev server
  • Next.js, Nuxt — starts on the right port
  • Any framework with a dev server

Inspecting images

When the selected model cannot inspect images directly, Sparky can use the ImageView fallback for supported workspace images or the current browser preview. Enable ImageView in General settings, then ask Sparky to inspect a screenshot or image and include a precise visual question.
