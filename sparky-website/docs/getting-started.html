Quickstart

Install Sparky 1.1.2, connect an AI provider, open a project, and complete your first reviewed task.

Step 1: Download Sparky

Grab the latest build from the download page.

SystemChooseFirst-launch note
Windows x64EXE installerThe current build is unsigned. In SmartScreen, choose More info, verify the app name, then choose Run anyway only if you trust the source.
macOS Apple SiliconApple Silicon DMG or ZIPIf macOS cannot verify the app, use the Finder or Privacy & Security confirmation for the downloaded Sparky app.
macOS IntelIntel DMG or ZIPUse the Intel package and the same macOS confirmation flow when required.
Linux x64AppImageUse the Linux package shown by the current published release. Availability is determined by that release bundle.

Read What's new in Sparky 1.1.2 for the complete cross-platform feature guide.

Step 2: Add your API key

Open Sparky, go to Settings, Models, choose your provider, and add the required API key or supported account connection. Credentials remain specific to that provider.

Step 3: Pick an AI model

Sparky discovers models and supported controls from provider metadata. The model picker shows the reasoning levels and context information the provider reports; exact entries can change without a Sparky update.

Step 4: Open a project

Choose the project folder Sparky should work in. Files, Terminal, Diff, browser preview, local search, project memories, and tool context all follow the active workspace.

Step 5: Choose Plan or Build

Use Plan when you want Sparky to inspect the project, ask necessary questions, and produce a read-only implementation plan. Use Build when you want it to edit files, run commands, and carry the task through verification.

Step 6: Give a bounded first task

State the outcome, constraints, and verification. For example: “Update the empty state in src/pages/Search.tsx, preserve the existing colors, run the focused component test, and show me the diff.”

Watch the tool timeline, then review the changed files, terminal output, and final summary. Follow up in the same session so the provider conversation and transcript continue instead of restarting.

Step 7: Save durable context

Open Settings, Memory to save preferences or project rules you want Sparky to reuse later. Keep temporary task details in the session; use Memory for facts that should remain useful in future conversations.
