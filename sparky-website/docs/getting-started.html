GETTING STARTED

Quickstart

Get Sparky running in five minutes. All you need is the app and an AI account.

Step 1: Download Sparky

Grab the latest build from the download page.

Step 2: Add your API key

Open Sparky, go to Settings, and paste your API key:

Step 3: Pick an AI model

Sparky works with whatever AI you already have. The app discovers available models automatically from your API key. Click a provider below to get started:

ProviderGet your API key
Anthropic (Claude)console.anthropic.com
OpenAI (GPT)platform.openai.com
Google (Gemini)aistudio.google.com
OpenCode Zenopencode.ai

Step 4: Start coding

Open Sparky, point it at your project folder, and tell it what you need in plain English. It reads your project, figures out the structure, and starts working.
