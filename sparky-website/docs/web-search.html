Web Search

Look up documentation, find solutions, and fetch current references from the web.

How it works

Sparky can search the web without any API key or extra setup.

When to search

Sparky searches automatically when it needs current information. You can also ask directly:

Example prompts
"Search for React useEffect cleanup"
"Look up Rust tokio spawn API"
"Find the Next.js 15 migration guide"

Tips

  • Prefix with language/framework for better results
  • Search before guessing — Sparky will search automatically
  • Include the error message — exact error text finds solutions
