Important clarification

UI foundation and runtime dependencies are separate.

Sparky's project position is that T3 Code was used as a UI foundation, not as a hosted AI service or a substitute for Sparky's product work. The current desktop/server source is separate from that UI relationship.

However, the current source still includes @anthropic-ai/claude-agent-sdk and a Claude provider adapter. It is therefore not accurate to say that the current build uses no Claude Agent SDK or no AI SDK. The dependency is listed below with its vendor terms.

That statement can only be changed after the Claude provider implementation and dependency are removed, the application is rebuilt, and this inventory is regenerated from the resulting release.
