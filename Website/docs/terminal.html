TOOLS

Terminal Commands

Build, test, install, lint — Sparky runs any command in your project's terminal and shows you the full output.

How it works

Sparky can run any shell command in your project's directory. It captures stdout, stderr, and the exit code, then shows you the results. You control the timeout — default is 300 seconds.

Running commands

Just tell Sparky what to run. It figures out the right command for your project (npm, cargo, python, go, make, etc.).

Example prompts
"Run the tests"
"Install the dependencies"
"Build the project"
"Run the linter and fix any errors"

Long-running commands

Some commands take a while — large test suites, builds, deployments. Sparky handles these in the background and shows results when they finish. You can press Ctrl+C to interrupt.

Tip: For dev servers or watchers that run indefinitely, start them in a separate terminal. Sparky works best with commands that have a clear end.

Timeouts

Commands time out after 300 seconds by default. If your task needs more time, ask Sparky to increase the timeout or break it into smaller steps.
